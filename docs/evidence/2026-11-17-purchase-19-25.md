synthetic users/catalogue and unmodified copies of Woo11.3.0, Bridge0.2.9,
Wallet1.7.4, Pinova1.3.0 and Gateland2.5.2 were used. No production customer,
order, receipt, provider credential or full database was copied. Mail, remote HTTP,
raw outbound socket/curl helpers and cron/async scheduling were blocked. Chromium
ran with its sandbox enabled; browser external origins were blocked.

Nine native commands passed570 executed PASS assertions: account auth25, cart107,
checkout UI117, account rendering83, received179, receipt20, template scope18,
multipart2 and display19. Checkout UI reuses107 guarded cart assertions; this is an
execution count, not570 distinct cases. Initial clean-environment cache/config
failures were resolved in the private clone and the affected commands rerun; they
were not counted as product failures or successful acceptance.

Actual Chrome verified guest typing while selection is pending, signed-in native
checkout/asset loading, silent plan replacement retaining native checkout/coupon
outer forms, native coupon/total updates, required terms and contact-free purchase.

real `process_payment`, charge, message or provider issuance was performed.

keyboard operation and long-name/large-amount coverage. There were no page errors.

Real-browser regression cases also passed: confirmedA→pendingB→no-plan category→A,
new gateway discovered only for the newly eligible plan, one-time native asset and

browsers or other plugins after removing a browser API they themselves require.
